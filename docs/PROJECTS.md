# Selected work

## Sharky's Room

An interactive 3D room for sharing my project experience and everyday life. Visitors explore the room's objects to discover projects, education, photos and contact information.

**Stack:** TypeScript, React, Next.js, Three.js / React Three Fiber, GSAP and Supabase. Confirmed in the project's dependency manifest and published portfolio content.

[Explore the live room →](https://sharkytang.com/)

## ROLUNE

A 3D board-game prototype for WeChat Mini Games, developed with Cocos Creator and TypeScript. Its verified core prototype includes dice movement, turns, property purchases, rent, chance events, jail and transport tiles.

The `Monopoly3D` repository contains the baseline prototype. This profile does not claim a public release or completed online multiplayer. Its source is private; the card uses published ROLUNE brand artwork, which is not a gameplay screenshot.

**Stack:** Cocos Creator 3.8.8 and TypeScript.

[Browse published portfolio project notes →](https://sharkytang.com/projects)

## FOLDORA

The latest local version focuses on an editable design asset library. Users can start with reusable assets, edit text, colours and layout, keep independent designs locally, and export PNG or JPG. Administrators prepare, test and publish assets to the library.

**Stack:** TypeScript, React, Next.js, Konva and IndexedDB. Earlier packaging projects retain basic 3D previews and RGB dieline proof exports; the profile describes the current asset editor as its main focus.

The application runs locally and its source is private. The screenshot shows the actual editor with a development sample asset. It does not represent a customer's artwork or a public hosted service.
