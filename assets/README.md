# SHARKY.OS artwork

Palette: background `#050B12`, panel `#091522`, border `#183A5A`, blue `#58A6FF`, text `#D6E7FF`, muted `#8FA8C5`, status `#39D353`.

Hero, identity, three project cards, tech stack, activity and footer each have desktop/mobile SVGs. All are self-contained with title/description metadata. Menlo / Consolas / monospace use system fonts; the hero wordmark is vector pixel geometry.

| Family | Role |
| --- | --- |
| `hero*.svg` | SHARKY.OS branding and actual room screenshot |
| `identity*.svg` | Two identity/current panels; stacked on mobile |
| `project-*.svg` | Unified cards; actual screenshots or labelled brand artwork |
| `tech-stack*.svg` | Verified tools without badges or proficiency scores |
| `activity*.svg` | Generated contribution history; do not edit counts manually |
| `footer*.svg` | Static logout line, tagline and small shark illustration |

README `<picture>` selects mobile artwork below a 700 px viewport. Links surround the cards; SVG labels are not separate controls. Image sources and TODOs are in [PROFILE_CONTENT.md](../docs/PROFILE_CONTENT.md). Original `profile-terminal*.svg` and `wechat-badge.svg` remain available for reuse.
